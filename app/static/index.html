Market data is never clean. Can Muse catch it?

Muse Spark reads a CSV of market data, flags duplicates, gaps, bad prices and unadjusted splits, and explains each one in plain English. A deterministic scorer then checks its answer.

How it works

Generate, test, score

1generator.py

Generate messy data

A seeded random walk produces clean prices. Known problems are planted at recorded rows, which becomes the answer key.

2muse-spark · muse-glimmer

Test the model

The CSV goes to a Muse model, which returns each problem it finds with the affected rows and an explanation.

3scorer.py

Score it

The scorer counts caught, missed and falsely flagged problems against the answer key and returns one number.

score → training reward for fine-tuning Glimmer
